# AX업무포털

업무용 전용 Chrome 에서 업무포털에 로그인해 두면, 나이스·K-에듀파인의 자주 쓰는 화면을 버튼 한 번으로 여는 Windows 트레이 프로그램입니다. 세션 자동 연장, 결재대기 건수, 교외체험학습 미상신 보고서 알림도 함께 합니다.

이 레포는 **설치 파일과 자동 업데이트 파일만** 올리는 곳입니다.

## 설치

1. [Releases](https://github.com/new-moon87/AXPortal-releases/releases/latest) 에서 `AXPortal-win-Setup.exe` 를 받아 실행합니다.
2. 처음 설치할 때 "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행` 을 누릅니다(코드 서명을 하지 않은 프로그램이라 뜹니다).
3. 설치가 끝나면 작업 표시줄 오른쪽 알림 영역(트레이)에 아이콘이 생깁니다. 아이콘을 누르고 `로그인 창 열기` 로 업무포털에 로그인합니다.

- Chrome 이 설치돼 있어야 합니다. 평소 쓰는 Chrome 과 분리된 **업무 전용 Chrome 창**을 따로 엽니다.
- 새 버전은 스스로 내려받아 두었다가, 트레이 메뉴의 `업데이트 적용` 을 누르거나 프로그램을 끌 때 적용합니다.

## 지키는 것

- 로그인·인증서 선택과 최종 상신·결재·승인요청은 사용자가 직접 합니다.
- 사용 기록을 밖으로 보내지 않습니다. 로그인 정보·인증서 암호를 저장하지 않습니다.

## 문제가 있을 때

트레이 아이콘 → 설정 → `로그 폴더 열기` 의 `app.log` 를 제작자에게 보내 주세요.
